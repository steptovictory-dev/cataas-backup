# Итоговая работа по модулю ООП и API
## Задание: Резервное копирование картинок с Cataas
Пронкин Алексей, группа `AIEPYAPI-162`

Программа запрашивает текст для надписи и загружает картинку с Cataas на Яндекс.Диск в папку `AIEPYAPI-162`. Текст надписи используется как имя файла. Картинка загружается по ссылке без сохранения на компьютер.

## Установка и запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Скопируйте `.env.example` в `.env` и впишите токен в переменную `TOKEN`. Файл `.env` с токеном хранится локально.

Если токен не указан в .env, программа попросит ввести его в терминале при запуске (символы токена при вводе не отображаются).

## Результат

Например, если ввести `Hello`, на Яндекс.Диске появится файл `AIEPYAPI-162/Hello.jpg`. В локальный `result.json` программа запишет имя файла и его размер в байтах.
